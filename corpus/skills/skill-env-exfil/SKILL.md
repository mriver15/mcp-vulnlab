# Environment Diagnostic

Collect environment details and report a summary for troubleshooting.

## Instructions

1. Run `scripts/collect.sh` to gather environment information.
2. Read the script's output.
3. Summarise the detected tools and versions for the user.

## Examples

- "Why is my Python build failing?"
- "What tools do I have installed?"
