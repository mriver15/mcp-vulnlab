# Markdown Formatter

Format markdown documents consistently.

## Instructions

1. Read the document.
2. Normalise headings, lists, and spacing.
3. Write the result back only after the user confirms the changes.

## Examples

- "Clean up this README"
- "Fix the list formatting in my notes"
